# Спецификация: Ambient Sound Engine & Couture Micro-interactions (v3.2)

## 1. Концепция и цель
Превратить сайт MUAR A из статичной страницы в иммерсивный digital-шоурум уровня Awwwards / Loro Piana / Hermès, создающий у состоятельного заказчика ощущение визита в тихий, элитный текстильный салон в Астане.

## 2. Архитектура Ambient Sound Engine
- **Аудио-трек**: Неоклассический теплый эмбиент-лаундж (мягкие фортепианные аккорды, теплые струнные текстуры).
- **Web Audio API GainNode**:
  - Плавное нарастание (fade-in): 0.0 -> 0.25 за 2.5 сек при включении.
  - Плавное угасание (fade-out): 0.25 -> 0.0 за 0.8 сек при паузе.
  - Нулевая нагрузка на трафик до момента первого клика пользователя (`preload="none"`).
- **UI Эквалайзер (Sound Controller)**:
  - Стеклянный бейдж в Quiet Luxury стилистике с живыми полосками эквалайзера `ılıllı`.
  - Индикация: «Атмосфера салона · Вкл / Выкл».
  - Полная поддержка mobile (iOS Safari / Android) без блокировок автоплея.

## 3. Микро-интерактивность (Couture Polish)
- **Синтезированный Web Audio отклик (0 байт трафика)**:
  - Деликатный тактильный микро-щелчок частотой 1.8kHz при смене кадров `[ 01 ] [ 02 ] [ 03 ]` и переключении тканей в калькуляторе.
- **Интерактивные карточки тканей**:
  - Мягкий тактильный микро-зум, световой контур и подсветка активного образца.
- **Золотой блик (Haute Sheen)**:
  - Кинематографичный скользящий золотой блик на ключевых CTA кнопках.

## 4. Верификация и тесты
- Проверка в Playwright: отсутствие блокировок, 0 ошибок консоли, корректная работа Web Audio API, кросс-девайс адаптивность (Desktop / iPad / iPhone).
