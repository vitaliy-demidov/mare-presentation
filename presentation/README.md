# MARÉ Decorative Studio · Executive Interactive Deck

Премиальный автономный интерактивный веб-презентатор для продажи проекта **Цифрового Флагмана MARÉ Decorative Studio** (Астана, Казахстан) за максимальный бюджет.

---

## 🎯 Назначение артефакта

Презентатор разработан для демонстрации клиенту (фаундеру студии и инвесторам) того, как технологический стек, эстетика **Dark Luxury Liquid Glass 2026** и живые интерактивные модули (калькулятор драпировок, световой 3D-симулятор, персональные КП и Voice AI) увеличивают средний чек студии до **5–15 млн ₸**, повышают конверсию топовых дизайнеров интерьера в **3.8 раза** и окупают разработку за 1–2 закрытые сделки.

---

## 🚀 Как запустить локально

Презентация полностью автономна и не требует сборщиков (Node.js, Webpack, Vite не нужны):

```bash
# Вариант 1: Запуск встроенного веб-сервера
cd "/Users/vitalij/Downloads/шторы нов/presentation"
python3 -m http.server 8000

# Откройте в браузере:
http://localhost:8000
```

Или откройте файл напрямую в Google Chrome / Safari / Edge:
```
file:///Users/vitalij/Downloads/шторы нов/presentation/index.html
```

### 📱 Версия для смартфона и пересылки в WhatsApp (`mobile.html`)

Для отправки клиенту в WhatsApp создана специальная мобильная версия **`mobile.html`**:
- Открывается прямо во встроенном браузере WhatsApp / Safari / Chrome на iPhone и Android.
- Управление в формате **Instagram / Telegram Stories** (тапы слева/справа, свайпы пальцем, верхний прогресс-бар из 7 сторис).
- Понятный язык для владелицы бизнеса: 7 экранов с крупными карточками и тактильными симуляторами без мелкого текста.
- Прямая ссылка: `http://localhost:8000/mobile.html` или файл `presentation/mobile.html`.

## ⌨️ Управление и горячие клавиши (Presenter Mode на десктопе)

| Клавиша | Действие |
| :--- | :--- |
| **`→`** / **`PageDown`** | Следующий слайд |
| **`←`** / **`PageUp`** | Предыдущий слайд |
| **`Space`** (Пробел) | Пауза / Возобновление автовоспроизведения (таймер 7.5 сек) |
| **`F`** | Вход / Выход из полноэкранного режима (Fullscreen) |
| **`Esc`** | Выход из модальных окон / Fullscreen |
| **`?`** | Быстрая шпаргалка по горячим клавишам |
| **Хэш в URL** | Прямые ссылки на слайды: `#slide-1` ... `#slide-8` |

## 💎 Структура 8 слайдов и живых виджетов

1. **Слайд 01: Цифровой Флагман vs Салон штор**
   * Интерактивный тумблер парадигм: «Старый салон (Tilda, цветы, скидки)» vs «Цифровой Флагман MARÉ (Архитектура света, VIP-статус)».
   * Фоновое кинематографическое видео и метрики чека (от 350k до 15 млн ₸).
2. **Слайд 02: Инженерный Конфигуратор & Геометрия Драпировок**
   * Выбор коэффициента драпировки: Волна (1:2.0), Французская тройная (1:2.5), Бантовая (1:2.8).
   * Слайдер длины карниза (2.5м – 8.0м), моторизация Somfy Glydea Ultra.
   * Живая динамическая SVG-волна складок и мгновенный пересчет сметы в тенге (₸).
3. **Слайд 03: Живой Симулятор Сценариев Освещения (3D)**
   * Переключение световых режимов: День (5500K) / Вечер (2700K) / Ночь (100% Blackout).
   * Реальный cross-fade переход локальных фотоинтерьеров Астаны.
   * Пояснение конверсионного триггера: рост закрытия дизайнеров в 3.8 раза.
4. **Слайд 04: Интерактивное «Цифровое КП»**
   * Поле ввода секретного кода (`VILLA`, `70`, `140`).
   * Отображение персонального досье с адресом (BI Village Deluxe, пос. Саранда, Talan Towers), тканями (Wind Pure, Dedar, Casamance) и кнопкой прямого акцепта в WhatsApp.
5. **Слайд 05: Архитектура «Две Двери» (B2C & B2B)**
   * Интерактивное переключение: [ B2C: Частные Резиденции ] <---> [ B2B: Посольства и Корпорации ].
   * Огнестойкость Trevira CS КМ1, звукопоглощение NRC 0.85, НДС 12%, договоры ТОО, цех 350 м² в Астане.
6. **Слайд 06: Voice AI Консьерж & PWA Мобильность**
   * Демо голосового ввода с Canvas-визуализацией звуковой волны в реальном времени.
   * Мгновенное извлечение сущностей (комната, метраж, ткань, электропривод) без клавиатуры.
   * PWA бейдж: автономное приложение для iOS/Android без магазинов.
7. **Слайд 07: Прозрачная Декомпозиция Трудоемкости (155–225 часов)**
   * Интерактивный аккордеон 5 этапов разработки с артефактами и результатами.
   * Обоснование оценки и спринтовая модель сдачи работ.
8. **Слайд 08: Инвестиционная Модель, ROI & Выбор Подрядчика**
   * Интерактивный ползунок окупаемости: закрытые виллы в месяц -> расчет чистой прибыли студии (от 4.8 до 19+ млн ₸) и окупаемости за 14–22 дня.
   * Сравнительная матрица: Фрилансер vs Бутиковая студия (ОПТИМУМ) vs Топ-агентство.
   * Финальная кнопка действия «Запустить проект в WhatsApp».
